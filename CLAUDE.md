# PROJEKT-MASTERFILE – HAARSCHARF
Gilt zusätzlich zur globalen Masterfile (~/.claude/CLAUDE.md).

## 1. Ziel und Endprodukt
Musterwebseite (Demo für Kaltakquise) für Friseursalons / Barbershops. Fiktive Marke HAARSCHARF.
Modern, cool, praxisbezogen, löst echte Friseur-Probleme:
- Telefon klingelt beim Schneiden → Online-Termin 24/7, Stylist wählen
- No-Shows / Lücken → Erinnerung, Warteliste, Last-Minute-Lücken
- Beratung / Preis vorher unklar → Look-Finder / Haarfoto schicken
- Fachkräfte- und Azubimangel → eigenes Recruiting-Kapitel (Film + 60-s-Bewerbung)
- Bewertungen (Beispiel-Karten, markiert), Gutscheine
